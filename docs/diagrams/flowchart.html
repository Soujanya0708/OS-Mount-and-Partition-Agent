Step 1

Natural Language Input

The terminal user executes mount-agent "Mount ubuntu.iso". No technical flags or block device knowledge required.

Step 2

Unix Domain Socket IPC

The CLI sends the instruction payload to /run/mount_agent.sock, where the privileged root service daemon is listening.

Step 3

Intent & Parameter Parsing

The agent parses the intent using local LLM / rules, extracting target ubuntu.iso and selecting mount_target tool.

Step 4

Loopback Mapping (losetup)

Because an ISO is a file, the agent uses losetup -fP to allocate a virtual block device (e.g., /dev/loop0).

Step 5

Filesystem Detection

The agent runs blkid / file -s to verify the filesystem format is iso9660.

Step 6

Kernel mount() Syscall

Directly invokes the Linux mount() system call with safety flags MS_RDONLY | MS_NOSUID | MS_NODEV to /mnt/agent/ubuntu.
